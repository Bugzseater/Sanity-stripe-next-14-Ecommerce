# Sanity + Stripe E-commerce (Next.js 14)

A modern e-commerce web application built using Next.js 14 with Sanity CMS for content management and Stripe for secure online payments.

## 🚀 Features
- Product management using Sanity CMS
- Secure online payments with Stripe
- Modern and responsive UI
- Dynamic product pages

## 🛠 Tech Stack
- Next.js 14
- React
- Tailwind CSS
- Sanity CMS
- Stripe

## 🎯 Purpose
This project demonstrates building a real-world e-commerce application using modern frontend technologies and third-party integrations.

## ▶️ How to Run
1. Clone the repository
2. Install dependencies using `npm install`
3. Add environment variables
4. Run the project using `npm run dev`
